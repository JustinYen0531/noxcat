這一週，怎麼活

你不是要消滅魔王，而是要在七天裡，把更多時間變回自己的生活。披薩會自己轉動；輪到你的那一片時，選擇要把什麼放進去。

01 // READ THE CLOCK

只操作南方金框裡的那一片

一整天被切成十二片，每片代表兩個小時。披薩每 3 秒順時針前進一次；只有來到南方金框的時段可以操作。北方是魔王，西方則會讓事件產生結果。

02 // MAKE A CHOICE

甜料是今天的選擇，餅皮是長期生活

甜料會累積收益、削弱魔王，並慢慢把無主時間變成你的。等級越高，改變越快。改造餅皮成本較高，但能立刻拿回一片；已經是你的餅皮也能繼續強化。

03 // KNOW THE DIFFERENCE

Nox 能清除摩擦，不能替你過人生

遇到紅色辣椒先看它是哪一種。Gas、跨鏈等技術摩擦可交給 Nox，每天免費 3 次；加班、支出等生活壓力則要由你花費資源處理。

04 // READ THE PIZZA

看顏色，就知道時間屬於誰

金色是你的生活，暗紅色屬於魔王，米色仍是無主時間。櫻桃代表甜料，辣椒代表壓力。數字是餅皮價值；價值歸零，這片時間就會失去原本的主人。

05 // PREPARE TOMORROW

每天結束，先替明天準備

十二片走完後會有 15 秒採購。預先買好甜料和餅皮，比白天臨時購買便宜；Nox 每天還會送你一份小確幸。第七天結束後，遊戲會看你拿回多少生活、累積多少價值，以及還留下多少資源。

記住就好：先看南方金框 → 判斷這片屬於誰 → 再決定加甜料、換餅皮或處理辣椒。你不需要每一片都贏；只是別讓整週都在替別人運轉。
