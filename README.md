# NOXCAT 披薩時鐘

12 片披薩＝一天 24 小時。披薩順時針旋轉，玩家（南）與魔王（北）爭奪每一段時間的「餅皮」所有權，7 天後結算幸福指數。一局約 5 分鐘（每片 3 秒、每天 15 秒採購可提早結束）。

## 執行

- 桌機：直接雙擊 `index.html`（不需伺服器、不需安裝）。
- 手機：把資料夾放到任何靜態伺服器，例如在專案目錄執行 `python -m http.server 8000`，手機同一個 Wi-Fi 開 `http://<電腦IP>:8000/`。
- 除錯參數：`index.html?autostart=1&speed=10`（跳過開始畫面、加速 10 倍）；`&demo=1` 預先擺幾個甜料看長相；`&touch=1` 在桌機模擬觸控裝置。

## 橫向版面與螢幕相容

- 遊戲是**橫向**：左欄狀態與事件記錄、中間披薩、右欄操作／採購。披薩直徑由畫面高度決定，寬度不夠時再縮到 46% 寬。
- 左右欄各有最小與最大寬度（104–240px、168–400px），整組置中，所以 667×375 的舊手機到 1920×1080 都不會擠爆或拉稀。
- 手機**直拿**時（觸控裝置且高 > 寬）整個畫面用 CSS 轉 90° 呈現橫向，開了方向鎖定也能玩。Android 按「開始」時另外嘗試全螢幕＋鎖橫向；iOS 不支援鎖定，靠 CSS 旋轉。
- 已用 headless Chrome 驗證：844×390、667×375、390×844（直拿旋轉）、1280×720、1920×1080。

## 操作

- 開始畫面提供「玩法教學」入口；前半以五張靜態說明卡配合現有程式繪製的披薩、甜料與辣椒，說明時鐘、操作、Nox、狀態判讀與每日採購；後半提供八個可收合的完整數據區，公開開局設定、甜料、辣椒、餅皮、經濟、魔王機率、結算順序與幸福指數公式。教學末尾可返回目錄或直接開始。
- 只能操作轉到**南方（金框）**的那片披薩，每片停留 3 秒，金框外圈的弧線是倒數。
- 觸控／滑鼠：點下方按鈕。桌機鍵盤：`1` `2` `3` 甜料、`Q` 餅皮、`W` 處理辣椒、`E` 賣出、空白鍵 結束採購。
- 右上 `Ⅱ` 暫停；切到背景分頁會自動暫停。

## 一天的流程

每片依序經過 **北（魔王干預）→ 南（你操作）→ 西（結算）**。12 步後進入 **15 秒採購階段**（披薩留在畫面上讓你規劃），買的東西進庫存、白天直接放。第 7 天結束直接進結局。

## 規則（實作版，數值在 `core.js` 的 `CFG`）

| 東西 | 意義 | 數值 |
| --- | --- | --- |
| 餅皮 | 長期生活模式：你 / 魔王 / 無主 / 被抽走 | 每次結算 +1 價值，無上限 |
| 甜料 Ⅰ / Ⅱ / Ⅲ | 小確幸 / 好習慣 / 生活自主 | $10 / $25 / $50 |
| 甜料在自家餅皮 | 賺錢 + 加速增值 | 收入 3 / 7 / 15，價值 +2 / +4 / +8 |
| 甜料在魔王餅皮 | 削弱對方價值，歸零→無主、甜料消失 | 每次結算 −4 / −9 / −20 |
| 甜料在無主餅皮 | 結算 **3 / 2 / 1** 次→變成你的餅皮（影響速度） | 同時賺收入 |
| 辣椒（魔王） | 技術摩擦（Gas、跨鏈、駭客）或生活壓力（加班、支出） | 每次結算扣 3 / 5 / 8，侵蝕你的餅皮 5 / 9 / 14，無主 3 / 2 / 1 次→魔王餅皮 |
| Nox 處理 | 免費清除**技術摩擦** | 每天 3 次 |
| 自己處理 | 花錢清除**生活壓力**（Nox 幫不上） | $20 |
| 買餅皮（採購） | 價值 10 / 20 / 30 / 45 | $40 / $55 / $70 / $93（25 + 1.5×價值） |
| 放餅皮（白天） | 無主：任一片；魔王／自家：**新餅皮價值必須更高**；優先用庫存剛好夠高的那片，沒庫存就急買 | 急買加價 25% |
| 賣出餅皮 | 生活換現金 | +價值 |
| 每日收入 | 第 2 天起 | +$70，扣掉「生活成本」 |
| Nox 製作甜料 | 每天採購階段送一份 | 甜料 Ⅰ ×1 |

### 魔王會做的事（北方）

- 撒辣椒（機率 30% + 5%×天數；等級隨天數 1→2→3；第 4 天起會把辣椒升級）。
- 抽走魔王餅皮上的甜料（25%）。有你的甜料的時間，魔王動不了餅皮。
- **抽走整片披薩**（第 3 天起 5%，只抽無主或價值 <15 的你的餅皮）：那片消失一圈，12 步後以無主狀態回來。
- **奪取／替換你的餅皮**（第 3 天起 15%，只換價值低於 8+4×天數 的餅皮）：換成價值 +3 的魔王餅皮。
- **突發支出**（第 2 天起 5%）：直接扣 $10+3×天數。
- **增加生活成本**（第 3 天起 4%）：每天固定支出永久 +$5。
- 第 4 天起 12% 直接把沒人經營的無主時間填滿。

### 結局

領地數、領地總價值、手握現金、Nox 處理次數 → 幸福指數 = 領地×15 + 價值 + 現金×0.3 − 魔王領地×8 − 殘留辣椒×3。你 ≥7 片大勝；比魔王多小勝；否則輸。

## 檔案

- `index.html`：UI、輸入、畫面流程（單檔可開）。
- `core.js`：純遊戲邏輯，不碰 DOM，可在 Node 跑。
- `tools/sim.js`：`node tools/sim.js 300` 模擬整局檢查平衡（idle / human / cautious / greedy）。
- `tools/check-tutorial.js`：核對玩法教學的八個數據章節是否與 `core.js` 正式規則一致。
- `tools/shot.js`：`node tools/shot.js screenshot "?autostart=1" 390 844 9000 out/game.png frame` 用 headless Chrome 截手機尺寸畫面。
- `docs/GDD.md`：原始設計文件。
- `docs/CONTENT_CATALOG.md`：4 種玩家餅皮、4 種魔王餅皮、15 種甜料與 15 種辣料的完整人生事件目錄，包含 NOXCAT 業務對應與品牌護欄。
