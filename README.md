# NOXCAT 披薩時鐘（最小可玩版）

12 片披薩＝一天 24 小時。披薩順時針旋轉，玩家（南）與魔王（北）爭奪每一段時間的「餅皮」所有權，7 天後結算幸福指數。一局約 5 分鐘。

## 執行

- 桌機：直接雙擊 `index.html`（不需伺服器、不需安裝）。
- 手機：把資料夾放到任何靜態伺服器即可，例如在專案目錄執行 `python -m http.server 8000`，手機同一個 Wi-Fi 開 `http://<電腦IP>:8000/`。
- 除錯參數：`index.html?autostart=1&speed=10`（跳過開始畫面、加速 10 倍）。

## 操作

- 只能操作轉到**南方（金色框）**的那片披薩，每片停留約 3.2 秒。
- 觸控／滑鼠：點下方 6 顆按鈕。桌機鍵盤：`1` `2` `3` 甜料、`Q` 餅皮、`W` 處理辛辣、`E` 賣出、空白鍵 繼續。
- 右上 `Ⅱ` 暫停；切到背景分頁會自動暫停。

## 規則（實作版）

| 東西 | 意義 | 數值（`core.js` 的 `CFG`） |
| --- | --- | --- |
| 餅皮 | 長期生活模式：你 / 魔王 / 無主 | 每次結算 +1 價值 |
| 甜料 Lv1–3 | 好習慣、小確幸、生活自主 | $10 / $25 / $50 |
| 甜料在自家餅皮 | 賺錢 + 加速增值 | 收入 3/7/15，價值 +2/+4/+8 |
| 甜料在魔王餅皮 | 削弱對方價值，歸零→無主、甜料消失 | 每次結算 −4/−9/−20 |
| 甜料在無主餅皮 | 結算 2 次→變成你的餅皮 | 也賺收入 |
| 辛辣（魔王） | 技術摩擦（Gas、跨鏈、駭客）或生活壓力（加班、支出） | 每次結算扣錢、侵蝕你的餅皮、無主 2 次→魔王餅皮 |
| Nox 處理 | 免費清除**技術摩擦** | 每天 3 次 |
| 自己處理 | 花錢清除**生活壓力**（Nox 幫不上） | $20 |
| 改造 / 奪回 / 強化餅皮 | 直接改變餅皮 | $40 / $40+2×對方價值 / $20（+8） |
| 賣出餅皮 | 生活換現金 | +價值 |
| 每日收入 | 第 2 天起 | +$70 |

流程：每片依序經過 北（魔王干預）→ 南（你操作）→ 西（結算）。每天結束有結算畫面（可跳過），第 7 天結束進入結局：領地數、領地價值、現金、幸福指數。

## 相對 GDD 的簡化（第一階段刻意不做）

- 沒有 15 秒採購階段：購買＝直接放到南方那片；每日結算畫面只做暫停與摘要。
- 魔王不會「抽走整片披薩」；只會撒辛辣、抽走魔王餅皮上的甜料、後期直接填滿無主時間。
- 沒有劇情過場、存檔、設定、進階動畫。角色（主角、Nox、魔王、LOGO）全部是 placeholder 框，等資產圖再換。
- 甜料的「等級效果」只反映在成本／收益／傷害數值上，沒有種類差異。

## 檔案

- `index.html`：UI、輸入、畫面流程（單檔可開）。
- `core.js`：純遊戲邏輯，不碰 DOM，可在 Node 跑。
- `tools/sim.js`：`node tools/sim.js 300` 模擬整局檢查平衡（idle / human / cautious / greedy 四種策略）。
- `tools/shot.js`：`node tools/shot.js screenshot "?autostart=1" 390 844 9000 out/game.png frame` 用 headless Chrome 截手機尺寸畫面。
- `docs/GDD.md`：原始設計文件。
